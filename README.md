HabitKernel
===
`HabitKernel` is an open‑source habit manager.
Create, mark, and edit your habits without restrictions.
This project is part of my hobby, i.e., a pet project.

## Goals

- [ ] Implement the `core` library for all clients.
- [ ] Implement the `CLI` client.
- [ ] Implement the `TUI` client.
- [ ] Implement a `web` client using `Tauri` or another framework for Android.
